Coverage and limits

Capture starts when this build runs with usage statistics enabled. Existing access logs cannot reconstruct historical token usage. Completed upstream execution attempts are recorded; authentication and validation failures before execution are outside this view. Failed attempts can have unknown token consumption. Cache hits mean a provider reported cache-read tokens, not a proxy response cache. A response-reported model is an upstream claim. Hidden routing inside an external provider is not observable.

The journal retains two segments of up to 32 MiB and the latest 100,000 retained attempts in memory. Old history is evicted as these bounds are reached. Writes are buffered by the operating system, so abrupt power loss can lose recent records. Persistence errors are shown above. No prompts, completions, API keys, OAuth tokens, or response headers are saved. Subscription price and quota conversion are not inferred from token counts.
